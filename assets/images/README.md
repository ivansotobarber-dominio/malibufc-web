## Carpetas

1. `club`, escudo, identidad visual y fotografías institucionales.
2. `equipo`, fotografías de equipos, partidos y plantilla autorizadas para publicación.
3. `productos`, fotografías del catálogo.
4. `patrocinadores`, logotipos autorizados de patrocinadores.

## Formatos

Priorizar:

1. SVG para escudo y logotipos cuando exista un archivo original válido.
2. WebP o JPEG para fotografías.
3. PNG cuando se necesite transparencia.

Conservar una copia del archivo original con la máxima calidad disponible. La optimización para la web se realizará después sin sustituir el original.

## Nombres

Usar nombres descriptivos, en minúsculas, sin espacios, tildes ni caracteres especiales. Separar palabras con guion.

Ejemplos:

`club/escudo-oficial.svg`

`equipo/primer-equipo-2026-2027.jpg`

`productos/camiseta-oficial-frontal.webp`

`patrocinadores/nombre-patrocinador.svg`

## Información necesaria

Al subir una fotografía, indicar qué muestra, fecha aproximada, autor o procedencia y confirmación de que puede publicarse. Para productos, indicar nombre, variante y si la imagen es definitiva. Para patrocinadores, confirmar el nombre oficial, enlace web y autorización de uso del logotipo.
