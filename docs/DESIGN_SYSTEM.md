# Design System Malibú FC

Estado: versión 0.1, 2026-08-16.

## Principios

1. El partido y la historia mandan la jerarquía.
2. La fotografía real aporta prueba y emoción.
3. Pocas familias de componentes, con usos claros.
4. La web resume; las páginas propias desarrollan.
5. Todo estado pendiente debe poder reconocerse.

## Componentes base

Header sticky, navegación responsive, hero editorial, matchday strip, portal de área, ficha de producto, galería, bloque de competición, alianzas, redes, contacto y footer legal.

## Tipografía

Los titulares usan una familia condensada y expresiva; el texto corrido utiliza una sans legible. La carga actual está en `index.html` y las reglas compartidas en `css/styles.css`.

## Estados

Confirmado, en construcción, diseño de referencia, pendiente de confirmar y demostración. Nunca ocultar el estado mediante un CTA que parezca operativo.

## Responsive y accesibilidad

Mobile first, foco visible, enlace de salto, navegación por teclado, controles con nombre accesible y reducción de movimiento. Los cambios deben probarse en móvil y escritorio antes de publicar.
