# Correo oficial y firma de Outlook

Fecha de confirmación: 2026-08-18.

## Correo oficial

El correo público del club es `info@malibufc.es`. La web lo utiliza mediante enlaces `mailto:`. La cuenta se gestiona actualmente desde Outlook de escritorio.

## Firma recomendada

La plantilla HTML reutilizable está en `docs/EMAIL_SIGNATURE_OUTLOOK.html`. Está diseñada para mensajes del club, con el nombre del equipo, correo, dominio e Instagram. No incluye teléfono personal, número de Bizum ni datos no confirmados.

## Instalación en Outlook de escritorio

1. Abrir el archivo HTML en un navegador y copiar la firma renderizada, no el código fuente.
2. En Outlook, abrir `Archivo`, `Opciones`, `Correo`, `Firmas`.
3. Crear una firma llamada `Malibú FC`.
4. Pegar la firma en el editor y seleccionar si se usará en mensajes nuevos y respuestas.
5. Enviar un correo de prueba a una cuenta propia y comprobar enlaces, tamaño y visualización en móvil.

La firma no debe incorporar información comercial, precios, datos de pago ni promesas de disponibilidad.
