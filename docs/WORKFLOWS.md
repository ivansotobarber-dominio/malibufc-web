# Workflows del ecosistema Malibú FC

Fecha: 2026-08-16.

## Convocatoria

Evento → disponibilidad en WhatsApp → registro en Google Sheets → cierre el sábado → convocatoria → confirmación → asistencia en 24 horas → revisión del dashboard.

## Contenido de partido

Objetivo → fuente confirmada → copy → revisión → publicación en web o red → archivo del asset → métrica y aprendizaje.

## Producto

Referencia → datos comerciales confirmados → catálogo → WhatsApp → confirmación de disponibilidad e importe → Bizum privado → registro restringido → entrega.

## Vídeo

Idea → tratamiento → guion → storyboard → assets → grabación o generación → edición → subtítulos → thumbnail → revisión → publicación manual → derivados → archivo.

## Historia y archivo

Fuente → fecha y contexto → permiso → clasificación → ficha histórica → asset relacionado → publicación solo si está confirmado.

## Acta y decisiones

Tema → acuerdo o pendiente → responsable → fecha objetivo → estado → evidencia → cierre. Las decisiones confirmadas se trasladan a `DECISIONS.md`; las tareas ejecutables a `BACKLOG.md`.
